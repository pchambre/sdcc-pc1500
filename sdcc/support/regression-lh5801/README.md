# LH5801 regression tests

Self-checking C programs run on an emulated PC-1500, plus the example
programs (Blackjack with stacked decks, LANDER, EDIT) played by script. Each test shows `OK` or `FAIL n` (the
first failed check, see `tests/check.h`); tests that need keys have a
`tests/<name>.script` for [pc1500runner](https://github.com/pchambre/pc1500emu)
(`tools/runner` in pc1500emu, which documents the script language).

```sh
export PC1500RUNNER=/mnt/c/Users/paulc/pc1500emu/build/tools/runner/Release/pc1500runner.exe
export PC1500ROM=/mnt/c/Users/paulc/Documents/PC1500/ROM1.BIN
support/regression-lh5801/run.sh            # everything
support/regression-lh5801/run.sh calls      # one test
```

Run from WSL (the compiler builds there); a Windows `pc1500runner.exe` works
too. `SDCCFLAGS` passes extra compiler options to every build, the runtime
library's included -- e.g. `SDCCFLAGS=--oldralloc run.sh` runs the suite
without register allocation (every value in memory), the fallback. Every test is built at 00C5 and run with 28K of contiguous RAM
(16K at 0000H + 2K + 10K at 4800H), after `NEW` reserves its RAM.

| test | covers |
|---|---|
| arith8, arith16, arith32 | + - * / % compare bitwise shift, signed and unsigned, boundaries; widening and narrowing |
| memory | arrays, 2-D arrays, pointers, structs, string.h (incl. the TIN/SIN/LIN/CIN memcpy, memset, strcpy, strlen), calls through pointers (reentrant) |
| compare | 16/32-bit compares, all six operators, as branches and values: against the largest literal, literals with zero low bytes, signed boundaries, variables (> and <= swap operands) |
| long | the 32-bit helpers: copies, constant stores, add/sub in place, into a third variable and into the right operand, self-aliasing, shifts (signed, unsigned, in place, by bytes and bits), negation, registers live around them |
| calls | mixed parameter sizes, 1/2/4-byte returns, nested calls, sprintf varargs |
| printf | sprintf's conversions, flags, widths, precision and modifiers, its count, and generic printf_large.c's quirks (the port has its own, smaller printf_large.c) |
| regparm | register parameters (first 1-byte in A, first 2-byte in X) in either order, with wider ones, as other calls' arguments, kept across the callee's own calls, unused |
| preserve | values kept in Y/U across calls to functions of the module that leave them alone (directly or through their own calls), and not across ones that use them or call the library |
| floatops | the port's float library against IEEE single precision (numpy), bit for bit: + - * / and the comparisons on ~180 operand pairs (random, plus ties, cancellation, carries, shifts past the guard bits), sqrtf on 50 values, every integer type to and from float (saturating). Generated by `float_cases.py > tests/floatops.c` |
| numeric | the ROM-number wrappers (pc1500.h): add, subtract, multiply, divide, square root, abs and STR$ on the real ROM |
| control | loops, break/continue, goto, ?:, && and \|\| short-circuit, switch |
| elements | in-place `s[k] op= c`, `s[i] op= c`, `p->f op= c` and `x op= c`: carries, borrows, masks, an unchainable constant, a pointer still needed afterwards, post-increments that must not fuse |
| overlay | overlaid locals survive call chains, calls as arguments, calls through pointers (taken by name or from an initializer) and recursion |
| init | zeroed and initialized globals, static locals, const tables, rand()'s seed |
| heap | malloc, calloc, realloc, free on the default 1K heap: no overlap, contents kept, space back after free, NULL when too big; sprintf into a block |
| exitret | exit() from inside nested calls returns to BASIC |
| library | keyWait/keyScan, lcdInputLine, lcdSetCursor, the 26-cell limit, beep, lcdInvert |
| blackjack | the example game: 3:2 blackjack, split, double, push, end statistics |
| lander | the example game: float physics, sqrtf, sprintf; a perfect Moon landing and an Io crash, checked to the tenth |
| edit | the example line editor: insert, count, replace (lines growing and shrinking), sort, find, delete, browse; the buffer checked byte for byte |

`banked.sh` (2026-11-09) builds `banked/` with `build-lh5801.sh --banks=`
for a CE-1638, a CE-163F and the internal card, and runs each with the
device emulated and the banks' images loaded. main() calls into banks 1
and 2, between them nested and back, with arguments and results in A, X
and memory, a fixed function from a bank, `bank_select()`, then `exit()`
from inside bank 1. After every run the starting bank must be back in.
The card needs `PC1500EXPROM`, the expansion ROM (`rom_8800.bin`), whose
`BANK_RAW_ENTRY` at 8819H is the card's switch.

```sh
export PC1500EXPROM=".../PC1500-PSOC5/Design01_NonDMA_8K_PV_Swap.cydsn/rom/rom_8800.bin"
support/regression-lh5801/banked.sh            # ce1638 ce163f card
```

`src/lh5801/test_smoke.py` separately checks the exact linked bytes of a
minimal program (startup included).

## Profiling a regression-suite case

`profile.sh <support/regression/cases/x.c>` builds one of SDCC's own
regression cases as the suite does (after a suite run, for its gen/lh5801
objects), runs it on pc1500sim with `-p` (cycles per address) and prints
`slot_cost.py`'s split: stack-slot copies, the `__lh5801_fsave`/`frest`
call sites and helpers, and the rest of the module, in bytes and cycles,
per function. `SDCCFLAGS` passes extra options (`--opt-code-speed`).
A frame saved in line (1 byte, or up to 4 with `--opt-code-speed`) counts
as the function's own code.

Measured 2026-11-04 over the 14 cases that save frames: the helpers took
21-60% of a recursive function's time and stack slots under 7%; `frest`
then counted its loops in memory (now in XL, -29%).
